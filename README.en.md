# 🧟 ZOMB DIE

[![Bahasa Indonesia](https://img.shields.io/badge/Bahasa-Indonesia-red?style=for-the-badge)](README.md)
[![English](https://img.shields.io/badge/Language-English-blue?style=for-the-badge)](README.en.md)

### They come from the left. They come from the right. You have one weapon and one choice: **survive.**

The zombies never stop, and neither should you. Grab your gun, become **Leon**, and shoot your way as far as you can before they catch you. How far can you run?

**Think you've got what it takes? Beat your high score now!** 🔥

## 💀 Why You Need to Play

- 🧟 **Attacks from both sides.** Zombies spawn from the left and the right, so nowhere is safe.
- 📈 **The farther you go, the crazier it gets.** Zombies get faster and spawn more often as your score climbs.
- 🏆 **Chase the record.** Your high score is saved automatically, so you'll always want to beat yourself.
- 🔫 **Non-stop action.** Run, jump, and shoot in three directions.
- 🎧 **Tense atmosphere.** Background music and sound effects that keep you on edge.

## 🎮 Controls

| Key | Action |
|-----|--------|
| `A` / `D` | Move left / right |
| `W` | Jump |
| `←` / `→` | Shoot left / right |
| `↓` | Shoot down |

One touch from a zombie and it's **game over**. Don't let them get you!

## 🚀 Get Started

1. Install Python 3 and Pygame:
   ```bash
   pip install pygame
   ```
2. Clone this repo and run:
   ```bash
   git clone https://github.com/Ceryann/Zomb-Die.git
   cd Zomb-Die
   python main.py
   ```

> Make sure all image and sound files are in the same folder as `main.py`.
