# 🧟 ZOMB DIE

### Mereka datang dari kiri. Mereka datang dari kanan. Kamu cuma punya satu senjata dan satu pilihan: **bertahan.**

Zombie nggak pernah berhenti, dan kamu juga jangan. Ambil senjatamu, jadi **Leon**, lalu tembak sejauh mungkin sebelum mereka menangkapmu. Seberapa jauh kamu bisa lari?

**Berani coba? Pecahkan high score-mu sekarang!** 🔥

## 💀 Kenapa Kamu Harus Main

- 🧟 **Serangan dari dua arah.** Zombie muncul dari kiri dan kanan, jadi nggak ada tempat aman.
- 📈 **Makin jauh, makin gila.** Zombie jadi lebih cepat dan makin sering muncul seiring skormu naik.
- 🏆 **Kejar rekor.** High score tersimpan otomatis, jadi kamu akan terus penasaran mengalahkan dirimu sendiri.
- 🔫 **Aksi non-stop.** Lari, lompat, dan tembak ke tiga arah.
- 🎧 **Suasana mencekam.** Musik latar dan efek suara yang bikin tegang.

## 🎮 Kontrol

| Tombol | Aksi |
|--------|------|
| `A` / `D` | Jalan kiri / kanan |
| `W` | Lompat |
| `←` / `→` | Tembak ke kiri / kanan |
| `↓` | Tembak ke bawah |

Satu sentuhan zombie, **game over**. Jadi jangan sampai kena!

## 🚀 Mulai Main

1. Pasang Python 3 dan Pygame:
   ```bash
   pip install pygame
   ```
2. Clone repo ini dan jalankan:
   ```bash
   git clone https://github.com/Ceryann/Zomb-Die.git
   cd Zomb-Die
   python main.py
   ```

> Pastikan semua file gambar dan suara berada satu folder dengan `main.py`.
